Висновок
У ході виконання лабораторної роботи було опановано базові принципи об'єктно-орієнтованого програмування в C# шляхом створення та використання класу Car із власними полями, властивостями та методами.

Відповіді на питання
1. Що таке клас та об’єкт? Яка між ними різниця?
Клас — це шаблон (креслення або тип даних), який описує структуру, стан та поведінку майбутньої сутності.
Об’єкт — це конкретний екземпляр класу, створений у пам'яті за цим шаблоном.
Різниця: Клас існує абстрактно як концепт у коді, а об’єкт є реальним втіленням класу з власними конкретними значеннями даних.

2. Для чого використовуються конструктори? Чи може клас існувати без них?
Призначення: Конструктори використовуються для автоматичної ініціалізації об'єкта (задання початкових значень його полам та властивостям) у момент його створення за допомогою оператора new.
Чи може існувати без них: Ні, клас не може існувати без конструктора. Якщо розробник не написав жодного конструктора явно, компілятор C# автоматично створює стандартний конструктор за замовчуванням (без параметрів).

3. Чим відрізняється приватне поле від публічної властивості? Навіщо потрібна інкапсуляція?
Приватне поле (private): Перемінна всередині класу, що зберігає дані безпосередньо й доступна лише зсередини самого класу.
Публічна властивість (public): Спеціальний елемент класу, який дає зовнішній код доступ до приватного поля через блоки get та set, дозволяючи контролювати читання й запис.
Навіщо потрібна інкапсуляція: Вона приховує внутрішній стан об'єкта та захищає його від некоректного прямого зміни ззовні (наприклад, дозволяє додати перевірку на від'ємний вік чи невалідний рік).
