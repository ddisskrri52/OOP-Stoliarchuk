# Мета: Навчитися передавати поведінку як параметр через делегати Func, Action, Predicate, будувати на цій основі універсальні операції над колекціями та використовувати лямбда-вирази у практиці ООП. 

# Висновок
Під час лабораторної роботи було засвоєно роботу з колекціями, делегатами та лямбда-виразами. Було розроблено клас-утиліту із методом Map, який виконує перетворення елементів колекції за допомогою делегата Func<T, TResult>.

# Відповіді на питання
1. Що таке делегат і для чого він використовується?
Делегат - це тип, який представляє посилання на метод з певним списком параметрів та типом повернення.
Делегат використовується для передачі методів як параметрів.
2. У чому полягає різниця між Func та Action?
Action не повертає значення, а Func обов'язково повертає значення.
3. Як лямбда-вирази спрощують роботу з делегатами?
Лямбда-вирази надають компактний синтаксис для написання анонімних функцій, дозволяючи описувати логіку прямо на місці виклику делегата без необхідності створювати окремі методи в класі.
4. Які переваги дають узагальнені методи при роботі з колекціями?
Узагальнені методи (Generics) дозволяють методу працювати з різними типами даних, які вказуються при його виклику. Це забезпечує повторне використання коду та типобезпечність під час компіляції
