### Лабораторна робота №6 
## Тема: Наслідування. Ключові слова base, override, virtual. Приховування членів (new).
## Мета: Навчитися створювати ієрархії класів, використовувати ключові слова base, virtual, override для реалізації поліморфізму, а також розуміти відмінності між override та приховуванням членів за допомогою new. 
# Висновок: 
Під час виконання лабораторної роботи я на практиці опанувала створення ієрархій класів C# та використання механізму наслідування. 
За допомогою virtual та override я реалізувала поліморфну поведінку для обчислення площі різних фігур.
Також я зрозуміла різницю між перевизначенням методів та їх приховуванням через модифікатор new.

# Відповіді на контрольні запитання
1.  Поясніть принцип наслідування в ООП. Наведіть приклад з реального світу.
Наслідування дозволяє новому класу переймати поля та методи вже існуючого, щоб не писати однаковий код двічі.
Приклад: клас «Тварина» має загальну властивість «вік», а похідний клас «Пес» успадковує її та додає свою дію «гавкати».
2. Для чого використовується ключове слово base? Наведіть приклади його застосування.
Ключове слово base потрібне для звернення до базового класу з похідного.
Наприклад, щоб передати параметри в конструктор батьківського класу або викликати його оригінальний метод.
3. У чому полягає різниця між virtual та override? Як вони забезпечують поліморфізм?
virtual у батьківському класі дає дозвіл на зміну методу, а override у дочірньому — надає його нову версію.
4.  Коли варто використовувати модифікатор new для приховування члена базового класу, і які наслідки це має? 
new використовують, коли треба створити новий метод з таким самим ім'ям, як у батьківського класу, але без зв'язку з ним.
Головний наслідок — поліморфізм не працює: який метод викличеться, залежить тільки від типу посилання, а не від самого об'єкта.
