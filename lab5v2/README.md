# Тема: Поліморфізм: динамічне зв’язування та перевизначення методів. 
# Мета: Навчитися реалізовувати поліморфну поведінку за допомогою віртуальних методів та їх перевизначення, а також агрегувати результати поліморфних викликів. 

# Висновок
Під час виконання лабораторної роботи я опанував(ла) механізм поліморфізму та динамічного зв'язування в C#. 
На практиці створено ієрархію класів транспортних засобів із перевизначенням віртуального методу Move(), а також реалізовано обробку об'єктів у спільній колекції List<Vehicle> із подальшою агрегацією показника середньої швидкості.
Це демонструє, як поліморфізм робить код гнучким, зручним для розширення та легким у підтримці.

# Відповіді на контрольні запитання
1. Що таке поліморфізм і як він реалізується за допомогою virtual та override?
Поліморфізм — це можливість різних об'єктів виконувати один і той самий метод по-різному.
virtual у базовому класі дозволяє змінювати поведінку методу, а override у похідному класі задає для нього нову, власну реалізацію.
2. Що таке динамічне зв'язування та чим воно відрізняється від статичного?
Динамічне зв'язування визначає, який метод викликати, безпосередньо під час виконання програми (за залежністю від реального типу об'єкта).
На відміну від нього, статичне зв'язування визначає метод ще під час компіляції.
3. Як поліморфізм робить код гнучким і розширюваним?
Він дозволяє додавати нові класи (наприклад, новий транспорт Airplane) без зміни вже написаного коду та циклів.
Програма сама зрозуміє, як обробити новий об'єкт.
4. Переваги колекцій базових типів для поліморфних об'єктів?
Вони дозволяють тримати різні похідні об'єкти в одному списку (наприклад, List<Vehicle>) і обробляти їх одним циклом без зайвих перевірок умов через if чи switch.
