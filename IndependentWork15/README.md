## Самостійна робота №15 
# Тема: Делегати й лямбда-вирази: власні утиліти для колекцій
# Мета: Поглибити розуміння делегатів та лямбда-виразів через створення власних узагальнених методів утиліт для роботи з колекціями та повторного використання логіки.
# Відповіді на 4 завдання
1. Чому делегати корисні для створення таких утиліт?
делегатами можна передавати методи як параметри і це відокремлює загальний алгоритм перебору колекції від конкретної логіки операції, роблячи утиліти гнучкими та придатними для багаторазового використання з різними діями.
2. Як лямбда-вирази спрощують виклик цих методів?
лямбда-вирази дозволяють описувати потрібну логіку безпосередньо в місці виклику методу. Це позбавляє необхідності створювати окремі іменовані методи в класі для кожної дрібної операції, роблячи код коротшим і читабельнішим.
3. Map - аналог LINQ-методу Select(), що перетворює один тип даних на інший.  
Filter - аналог LINQ-методу Where(), який відфільтровує елементи за заданою умовою.   
MaxBy - аналог однойменного методу MaxBy() (з'явився в LINQ у .NET 6), що шукає максимальний елемент за певним критерієм.
ForEach - аналог методу List<T>.ForEach(). У стандартному LINQ для IEnumerable<T> такого розширення не існує, тому його часто доводиться реалізовувати самостійно або використовувати звичайний цикл foreach.

# Висновок
У цій роботі я закріпила на практиці використання делегатів та лямбда-виразів, створивши власні утиліти для колекцій. Я переконалася, що делегати роблять код гнучким, а лямбди значно спрощують його написання. Крім того, самостійна розробка цих методів дозволила мені краще зрозуміти внутрішню роботу стандартних операторів LINQ.

# Відповіді на контрольні питання
1. Чому делегати є зручним механізмом для передавання поведінки в узагальнені методи?
вони дозволяють відокремити загальний алгоритм від конкретної дії, роблячи узагальнені методи гнучкими та придатними для багаторазового використання з різною логікою.
2. У чому різниця між Func<T, TResult>, Action<T> та Predicate<T>? 
Func<T, TResult> - Приймає до 16 параметрів та повертає значення
Action<T> - приймає до 16 параметрів але не повертає значення
Predicate<T> приймає параметр та повертає bool значення
3. Які переваги дає поєднання generic-методів і лямбда-виразів під час роботи з колекціями?
узагальнення забезпечують безпеку типів та універсальність для будь-яких даних, а лямбда-вирази дають змогу передавати коротку логіку прямо під час виклику, уникаючи написання громіздких окремих методів.
4. У яких випадках власні утиліти на кшталт Map чи Filter корисно реалізувати самостійно, навіть якщо існує LINQ? 
з навчальною метою, для оптимізації у проєктах із жорсткими обмеженнями пам'яті чи ресурсів, або коли потрібна специфічна кастомна поведінка, якої немає у стандартній бібліотеці.
