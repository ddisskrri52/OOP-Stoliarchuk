## Самостійна робота No14
# Тема: Вивчення Dictionary<TKey, TValue> та HashSet<T> у бібліотеках .NET
# Мета: Дослідити реальні приклади використання узагальнених колекцій у популярних .NET-бібліотеках та зрозуміти, як вони застосовуються для вирішення практичних задач.
# Висновок
У роботі досліджено використання Dictionary<TKey, TValue> та HashSet<T> у System.Linq (.NET 10), що знижують складність пошуку й дедуплікації до O(1) у середньому. На практиці реалізовано кеш метаданих, менеджер тегів (UnionWith, IntersectWith, ExceptWith).
# Відповіді на питання
1. Generic-колекції у .NET забезпечують безпеку типів на етапі компіляції, позбавляють потреби в ручному приведенні типів та виключають операції пакування й розпакування (boxing/unboxing) для значущих типів, що економить пам'ять і підвищує швидкодію.

2. Dictionary<TKey, TValue> доцільно використовувати для миттєвого пошуку значень за унікальним ключем (наприклад, кешування метаданих за іменем файлу), тоді як HashSet<T> — для зберігання унікальних елементів без прив'язаних значень, швидкої перевірки їхньої наявності та операцій над множинами (UnionWith, IntersectWith, ExceptWith).

3. IEqualityComparer<T> визначає правила рівності для коректного розпізнавання дублікатів та алгоритм хешування (GetHashCode), рівномірний розподіл якого мінімізує колізії та утримує швидкодію операцій на рівні O(1).

4. У структурі Dictionary<string, HashSet<int>> зовнішній словник забезпечує пошук запису за словом за $O(1)$, а внутрішня множина HashSet<int> автоматично відсіює повтори номерів того самого документа й дозволяє шукати документи з кількома словами одночасно через швидкий перетин множин.
