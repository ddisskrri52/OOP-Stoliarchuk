## Лабораторна робота №10 
# Тема: LINQ в дії: фільтри, join, агрегації. Продуктивність. 
# Мета: Навчитися ефективно використовувати LINQ для фільтрації, об’єднання (join) та агрегації даних, а також аналізувати продуктивність LINQ-запитів. 
# Висновок
У процесі роботи було вдосконалено навички використання LINQ. Вимірювання, проведені за допомогою Stopwatch, показали, що синтаксис методів і синтаксис запитів працюють з однаковою швидкістю, оскільки вони компілюються в один і той самий код. Найшвидшими операціями виявилися проста фільтрація (Where) та проекція (Select). Натомість операції об’єднання (Join, Groupjoin) та агрегації (Count) виявилися найповільнішими, оскільки вони потребують порівняння ключів із двох колекцій і створення додаткових проміжних об’єктів у пам’яті.
# Відповіді на питання
1. Поясніть різницю між синтаксисом запитів та синтаксисом методів у LINQ. Коли який краще використовувати?
Синтаксис запитів нагадує SQL і краще читається при складних з'єднаннях, тоді як синтаксис методів із лямбда-виразами є гнучкішим і підтримує абсолютно всі операції. Синтаксис запитів краще використовувати для складних з'єднань та групувань, а систаксис методів є більш гнучким.
2. Для чого використовуються операції Join та GroupJoin? У чому їхня відмінність?
Join виконує внутрішнє з'єднання, а GroupJoin виконує ліве зовнішнє з'єднання з групуванням.
3. Наведіть приклади агрегуючих операцій LINQ та поясніть їхнє призначення.
Count(): рахує загальну кількість елементів.
Average(x => x.Age): повертає середнє арифметичне.
Min() / Max(): знаходить мінімальне чи максимальне значення у колекції.
Sum(x => x.Price): обчислює суму числових значень.
4. Як можна виміряти продуктивність LINQ-запитів? Які фактори впливають на неї?
Продуктивність вимірюється за допомогою класу System.Diagnostics.Stopwatch, використовуючи його методи StartNew(), Stop() та властивість ElapsedTicks або ElapsedMilliseconds.
На продуктивність впливає об'єм даних, складність алгоритму, відкладене виконання та витрати на виділення пам'яті під анонімні типи.
