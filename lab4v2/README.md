## Лабораторна робота №4 
# Тема: Наслідування. Ключові слова base, override, virtual. Приховування членів (new).
# Мета:Навчитися створювати ієрархії класів, використовувати ключові слова base, virtual, override для реалізації поліморфізму, а також розуміти відмінності між override та приховуванням членів за допомогою new. 
# Висновок:
Під час виконання лабораторної роботи №4 я навчилася створювати ієрархії класів у мові C# на прикладі базового класу Shape та похідних класів Circle і Rectangle.
Я опанувала використання ключового слова base для виклику конструктора базового класу, а також реалізувала поліморфну поведінку програми за допомогою модифікаторів virtual та override.
Крім того, я дослідила різницю між перевизначенням методів (override) та приховуванням членів базового класу за допомогою модифікатора new.
# Відповіді на контрольні запитання
1. Принцип наслідування в ООП та приклад з реального світу: Це механізм, який дозволяє похідному класу успадковувати поля, властивості та методи базового класу, створюючи ієрархію "є різновидом".
Приклад: Базовий клас Транспортний засіб (має швидкість, колір) $\rightarrow$ похідний клас Автомобіль (успадковує все та додає кількість дверей).
2. Для чого використовується ключове слово base? Для доступу до членів базового класу з похідного.
Використовується для виклику конструктора базового класу (наприклад, base(color)) або його методів.
3. Різниця між virtual та override:Відповідь: virtual вказує у базовому класі, що метод може бути перевизначений, а override у похідному класі надає нову реалізацію цього методу.
Разом вони забезпечують динамічний поліморфізм (виклик потрібного методу залежно від реального типу об'єкта).
4. Коли використовувати new та які це має наслідки?Відповідь: Модифікатор new використовується для явного приховування методу базового класу, коли створення нового методу не має бути поліморфним.
Наслідки: Виклик методу залежить від типу посилання (змінної), а не від типу об'єкта в пам'яті.Через посилання базового типу викличеться старий метод, а через посилання похідного — новий.
